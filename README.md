# Guild Ledger H4 — Google Research Harness²

Draft setup · 22 October 2026. Pins upstream Harness² and its credential-free deterministic demo. This is a separate adaptive-framework profile, not Antigravity, Gemini CLI or a fixed guidelines package.

Manifest SHA-256: `98ea2f392df4140dd18cceeecc6b09c442aafa090b50ef62ceba43b5f71f0af0`

Upstream: https://github.com/google-research/harness2, Apache-2.0; source commit `1cfe254e8d25b15f37048c3730134686abe60335`. Model-backed executors in the inspected release are OpenCode and Codex. No Claude executor is established. Our container permits only the upstream deterministic Python demo, with no model executables, credentials or network.

Native memory can carry lessons across ordered tasks. A future study must freeze the task order, isolate libraries between campaign replicates, and measure proposer/probe/compose/selection/reflection work. Independent evaluation stays outside all optimization loops. A frozen optimized harness would be a separate profile, tuned on disjoint development tasks then held fixed for evaluation.

The research repository owns the container tooling and comparison protocol. Research wrapper: https://github.com/orieken/guild-ledger-harness2. This repository packages a pinned upstream export; it is not an upstream fork. Paid optimization and benchmark invocation remain unauthorized. Apache license and third-party notices are retained in the image.
